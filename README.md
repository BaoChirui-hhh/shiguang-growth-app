# 拾光 · 个人成长记录

一款手机优先、可安装、可离线使用的个人成长记录 PWA，适合管理论文、秋招、知识沉淀与日常复盘。

## 功能

- 待办清单、面试题库、技术新知、重要话语、沟通表达、心得复盘
- 自定义模块、标签、搜索、完成进度和成长统计
- IndexedDB 本地数据库与浏览器持久化存储
- JSON 导入、导出备份
- 支持安装到 Android、iPhone 和电脑桌面
- Service Worker 离线启动

## 隐私

所有个人记录默认只保存在使用者自己的设备中，不会随网站源代码上传，也不会与其他使用者共享。清除浏览器网站数据或更换设备前，请先使用应用内的“导出备份”。

## 安装

- Android Chrome / Edge：浏览器菜单 → “安装应用”或“添加到主屏幕”
- iPhone Safari：分享 → “添加到主屏幕”
- 电脑 Chrome / Edge：地址栏右侧的安装按钮
